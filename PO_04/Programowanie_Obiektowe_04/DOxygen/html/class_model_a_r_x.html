Detailed Description

ARX (AutoRegressive with eXogenous input) model implementation.

This class implements a discrete-time ARX model with optional noise disturbance. The model follows the equation: y(k) + a1*y(k-1) + ... + an*y(k-n) = b0*u(k-d) + ... + bm*u(k-d-m) + e(k) where e(k) is optional Gaussian noise.
