\doxysubsection{Detailed Description}
ARX (Auto\+Regressive with e\+Xogenous input) model implementation. 

This class implements a discrete-\/time ARX model with optional noise disturbance. The model follows the equation\+: y(k) + a1\texorpdfstring{$\ast$}{*}y(k-\/1) + ... + an\texorpdfstring{$\ast$}{*}y(k-\/n) = b0\texorpdfstring{$\ast$}{*}u(k-\/d) + ... + bm\texorpdfstring{$\ast$}{*}u(k-\/d-\/m) + e(k) where e(k) is optional Gaussian noise.
